# AdbDesk icon concept v1

Generated with the built-in image_gen tool. Approved by the user and installed as the Windows application icon. Run `scripts/build-icon.ps1` to copy the source PNG and regenerate the multi-resolution ICO in `src/AdbDesk.App/Assets`.

## Generation prompt

Use case: logo-brand. Create one polished Windows desktop application icon for AdbDesk, an Android phone screen mirroring and device management utility. A single centered standalone icon, 1024x1024 square. Design: a bold cobalt blue rounded-square tile with a subtle restrained blue tonal gradient, carrying a striking white geometric symbol combining a desktop monitor and an upright smartphone overlapping its lower-right corner. The smartphone interior has a small cyan-blue screen. The monitor is a simple broad screen outline with a short centered stand; the upright phone is distinct and recognizable. Confident thick strokes and generous negative space, very few shapes, optical balance, clean contemporary professional software branding, front-facing flat vector-like design with crisp edges, no perspective. Must remain easily recognizable at 16, 24, 32 and 48 pixels. No fine details, no text, no letters, no Android mascot, no cables, no wifi arcs, no arrows, no ornaments, no watermark, no mockup, no presentation board, no multiple variants. Tile occupies approximately 88 percent of canvas, evenly centered. Outside rounded-square tile must be genuinely transparent, not a checkerboard, no surrounding shadow. This is the actual production icon asset, not a picture of an icon on a background.
