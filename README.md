# AdbDesk 安卓设备助手

Windows 10/11 x64 桌面工具。设备列表自动刷新，每台手机独立投屏窗口，鼠标键盘控制，APK 拖放安装。

主程序在同一 Windows 用户会话内只运行一份。再次双击会唤醒已有主窗口；不同手机的投屏窗口仍然可以同时打开。升级后首次使用请先退出旧版本。

## 使用

v1.0.0-beta.2 起支持应用内更新：右下角「检查更新」，启动时后台检查一次，确认后下载、验证签名并重启替换。首次请完整解压新版便携包；旧版 beta.1 需手动更新一次。发布流程、设置及故障恢复见 [更新说明](docs/updates.md)。

v1.0.0-beta.10（versionCode 10010）新增主界面投屏质量、音频、默认显示和启动全屏的自动记忆；更新诊断隐藏编译电脑的完整源码目录，保留类名、方法名、文件名和行号。保留独立设备显示设置、上下／左右铺满、自定义裁剪、熄屏／亮屏、外侧停靠工具栏及已有 ADB／网络抓包功能；旧版可开启“接收测试版本”后更新，详见[显示设置说明](docs/mirror-display.md)。

源码同步于 [GitHub](https://github.com/XieDH312/AdbDesk) 和 [Gitee](https://gitee.com/xiedh/AdbTools)，便携包及更新附件发布在 [GitHub Releases](https://github.com/XieDH312/AdbDesk/releases)。直接使用请下载 `AdbDesk-*-win-x64.zip`；Source code 压缩包需要自行构建。

1. 解压完整便携包，双击 `AdbDesk.exe`。保留旁边的运行库和 `tools` 文件夹。
2. 手机开启开发者选项、USB 调试，通过数据线连接，并在手机上允许电脑调试。主界面也会列出 ADB 已连接的网络设备。
3. 点击设备的投屏按钮，或勾选多台后批量投屏。窗口彼此独立，关闭一台不影响其他手机。
4. APK 拖入某台设备行或其投屏窗口，安装到该设备。拖到公共安装区域或点击安装按钮，会展示选中目标，确认后安装。
5. 底部全宽“运行日志”统一显示投屏输出和 APK 安装结果。主界面发起的安装进行时，可从日志栏的“取消安装”菜单选择指定任务取消；投屏窗口原生拖放安装无法在主界面取消。
6. 点击设备行的“截图”，预览该手机当前屏幕。无需启动投屏，USB 和无线连接均可使用；正在投屏时同样截取手机原始分辨率画面，不包含电脑窗口边框。
7. 点击设备行或投屏工具栏的“显示设置”，选择上下铺满、左右铺满或自定义裁剪，截图预览中可拖动选区并按设备记忆。工具栏停靠在窗口外侧；全屏或没有外侧空间时移到顶部边缘展开，离开后自动收起。应用显示设置时短暂重开这一台投屏。详见[显示设置说明](docs/mirror-display.md)。
8. 投屏工具栏还提供“手机熄屏”“手机亮屏”和“操作帮助”。熄屏后电脑端继续投屏和控制；悬停按钮可查看快捷键。操作帮助支持搜索、分类查看和复制，主界面右上角“使用帮助”也可打开。

主界面的投屏质量、传输音频、默认显示和启动全屏会自动记住上次选择，重开程序时恢复；修改对新打开的投屏生效。单台设备已经保存的显示方式和全屏设置仍优先生效。

截图预览支持“另存为…”选择 PNG 保存位置，“复制图片”后粘贴到聊天窗口或画图，以及点击图片／“查看原图”调用系统图片查看器。本次运行会记住上次保存目录；取消保存不会丢失当前预览。只有点击查看原图时才会在系统临时目录 `AdbDesk/Screenshots` 写入用于查看的临时 PNG，关闭预览后保留供图片查看器读取，可随系统临时文件一并清理。受手机安全保护的内容可能无法截取。

设备行显示设备名称、型号、Android 版本、连接方式和序列号。未授权或读取失败时保留设备条目；部分手机不提供自定义名称，会回退显示型号。

无线设备行的“断开连接”只断开当前这条无线 ADB 连接，同时结束本工具针对该连接的投屏，其他设备不受影响。同设备有主界面安装任务时，先等待完成或取消任务。断开不会关闭手机无线调试，也不会删除配对记录；共享此 ADB 连接的其他程序也会失去对该连接的访问。其他工具或系统自动发现可能再次连接该设备。

v1.0.0-beta.3 移除了独立的“安装任务”卡片。主界面选择 APK、设备行拖放及公共区域拖放仍使用安装队列，结果写入运行日志；安装进行时保留按任务取消入口。直接拖入投屏窗口的 APK 由 scrcpy 安装，输出也显示在运行日志中。

## 扫码连接 / 配对码连接（Android 11+）

底部状态栏显示电脑局域网 IPv4 和连接类型，点击地址复制，点击箭头查看其他网卡地址；悬停可查看子网掩码和网关。地址在启动时读取，之后由 Windows 网卡地址／网络可用性变化通知触发更新，连续通知合并延迟 300 毫秒处理，不再定时轮询 IP。复制、展开列表及连接前也会刷新，与 ADB 是否就绪无关。优先显示有网关的 Wi-Fi／有线网卡；WSL、VPN 等其他网卡列在展开菜单中。底部“设备每 2 秒刷新”仅指 ADB 设备列表。

连接前会结合实际子网掩码检查所有已识别的局域网地址。同一子网正常继续；不同子网或无法判断时显示电脑和手机地址，可选择“取消”或“仍然连接”。这是网络诊断提示，不保证同子网就一定可达，也不禁止已配置路由的跨子网连接。首页 IP 连接、配对码连接、扫码发现手机后、USB 开启无线均执行检查；取消不会提交本次配对、连接或 TCP/IP 切换。扫码尚未发现地址时无法比较，等待／过期提示会显示电脑 IP 及网络检查说明。

电脑通过 Windows 移动热点分享网络时，Wi-Fi Direct／Hosted Network 网卡显示为“电脑热点”，即使没有默认网关也参与网段判断；WSL、Hyper-V、VPN 网卡继续作为其他网卡处理。

设备卡片显示手机实际 Wi-Fi IP，并单独列出已识别的 VPN／隧道网卡地址，依据网卡来源区分，不把 `172.*` 等整个私网地址段当作 VPN。手机网络地址最多每 10 秒读取一次；点击地址会实时重新读取并复制，点击“刷新设备”也会重新读取，开启无线及确认后始终使用实时结果。读取失败时不拿 VPN 地址作为 Wi-Fi 备用。

手机开启 VPN 后，无线调试页可能显示 VPN 地址，而 Wi-Fi 详情仍显示实际局域网地址。此时打开“无线连接”，勾选“使用手机 Wi-Fi IP”，从下拉框选择 USB 手机的 Wi-Fi IP，或手动填写手机 Wi-Fi 详情中的地址。该选项只替换主机地址，保留原来的配对／连接端口；修改后刷新二维码或重新提交。自动发现同名、同类型服务有多个地址时优先同子网地址，不选择其他手机的服务。没有 USB 且发现不到服务时，改用配对码并填写实际 Wi-Fi IP 和配对弹窗的端口，连接端口仍取无线调试主页，不能混用或一概填写 5555。

“检测端口”只检查手动连接地址的 TCP 可达性，不提交配对或 ADB 连接；TCP 成功不代表 ADB 已认证。连接失败会展示实际目标及超时、拒绝、认证失败等提示。地址正确后若手机 VPN 仍阻止局域网流量，需要在 VPN 中配置局域网直连；应用无法替 VPN 放行网络。

首页“无线连接”左侧可直接输入手机 IP 和连接端口，点击“连接”或按回车。两个输入框之间的英文冒号由界面固定显示，无需手动输入。端口默认 `5555`，可修改；系统无线调试请填其主页显示的连接端口。该入口适用于已经配对或已经通过 USB 开启无线 ADB 的设备，首次配对仍使用“无线连接”窗口。连接结果显示在输入框下方，成功后自动刷新设备列表。

首页 IP 输入框右侧的箭头可查看最近 10 个成功连接的地址，选择后一起填入 IP 和端口，再点击“连接”。重复的地址会移到最前面，不同端口分别保留；失败或取消的连接不记录。重启时自动填入最近成功的地址，不自动连接。每条记录右侧的垃圾桶图标可单独删除该地址，不修改输入框或断开手机；菜单也支持清空全部历史。历史保存在当前 Windows 用户的 `%LOCALAPPDATA%/AdbDesk/connection-history.json`，换用新版便携包仍然保留；手机无线调试端口变化时需手动修正。

支持手机系统自带的“无线调试”，无需先插 USB。手机连接 Wi-Fi，电脑和手机位于可互通的同一局域网。部分定制系统没有此入口时，可继续使用下方的 USB 切换方式。

**扫码连接：**

1. AdbDesk 主界面点击“无线连接”，在弹出窗口选择“扫码连接”。
2. 手机进入“开发者选项 → 无线调试”，开启开关，再点“使用二维码配对设备”。
3. 使用该入口扫描电脑上的二维码。程序自动配对并尝试连接，确认连接成功后即可在设备列表投屏或安装 APK。
4. 二维码两分钟后过期，可点击刷新生成新码。关闭配对窗口或切换方式会停止等待和后续请求；已经提交给 ADB 的配对仍可能完成。请使用无线调试里的扫码入口，而非普通相机或微信扫一扫。

**配对码连接：**

1. 手机进入“无线调试 → 使用配对码配对设备”，保持配对弹窗打开。
2. AdbDesk 点击“无线连接”，在弹出窗口选择“配对码连接”，填写手机弹窗里的“IP 地址和端口”及六位配对码，再开始配对。
3. 程序配对后自动尝试连接。若只提示已配对，请回到手机的无线调试主页，填写该页“IP 地址和端口”到手动连接区域，然后连接。

手机的**配对端口**和**连接端口**是两个不同端口，不能混用，也不要固定填写 5555。配对码窗口可选的连接地址使用同一手机无线调试主页显示的地址，两处手机 IP 应一致。目前手动地址输入支持 IPv4。

扫码需要局域网自动发现（mDNS）。访客网络、AP 隔离或公司网络策略可能导致发现失败；此时可以改用配对码，手动填写两个地址。配对凭据只用于本次操作，不写入 AdbDesk 日志或配置；ADB 自身按系统机制保存已配对设备的信任关系。关闭本工具不会撤销已完成的配对；需要停用时，在手机无线调试中关闭开关或删除已配对电脑。

说明依据：[Android 无线调试文档](https://developer.android.com/studio/run/device#wireless)、[AOSP 配对协议](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/docs/dev/adb_wifi.md)。

## USB 切换无线连接

1. 手机和电脑接入同一可互通的局域网，手机连接 Wi-Fi，先插 USB 数据线并允许调试。
2. 在 USB 设备行点击“开启无线”。程序读取手机 Wi-Fi 地址，开启 ADB TCP/IP 5555 并尝试连接；提示连接成功后再拔数据线，从网络设备行投屏。
3. 要停止 TCP/IP 调试，重新插 USB 数据线，在 USB 设备行点击“关闭无线”，手机 ADB 会切回 USB 模式。

开关只对已授权的 USB 设备可用。切换会重启手机的 ADB 服务，可能中断投屏；安装期间请先等待任务结束。若提示无线模式已开启但连接失败，保留 USB，检查同网段、防火墙和路由器客户端隔离。

部分 Windows ADB 后端对 USB 设备的路径返回 `unknown`，程序会读取 ADB 提供的逐设备连接类型，按序列号、连接编号和状态匹配，支持多台 USB 手机同时识别并显示无线开关。连接类型每次刷新重新读取，型号等属性继续缓存；USB 拔插导致连接编号变化时重新获取详情。旧版 ADB 不支持该查询时，保留设备路径和单 USB 选择器作为备用；旧版后端同时插入多台且无法确认时仍显示“连接方式未知”，可暂时只保留目标手机的数据线。每次切换无线及网络确认后都会重新确认 USB 目标，不根据旧缓存或序列号外形猜测。

这里的“无线”指通过 USB 开启的 ADB TCP/IP，不是手机 Wi-Fi 开关，也不是 Android 11+ 的无线调试配对开关。请在可信局域网使用，用完关闭。操作依据见 [Android 官方 ADB 文档](https://developer.android.com/tools/adb#wireless)。

鼠标左键点击/拖动对应触摸，右键返回，中键回到桌面；快捷键行为以 scrcpy 官方文档为准。
投屏默认“清晰 · 1920 / 60 帧”，另有 1024 / 30、1280 / 30、2560 / 60 和 3840 / 60 可选。分辨率数字指最长边像素上限，帧率也是上限，实际输出取决于手机屏幕、编码能力和连接情况。质量选项对新打开的投屏生效，已经投屏的设备需停止后重新启动。多台投屏建议使用较低画质并关闭声音。

显示方式可选择“完整显示 · 保持比例”或“裁剪铺满 · 保持比例”，并可勾选“启动时全屏”。裁剪按 AdbDesk 当前所在电脑显示器的比例，读取手机有效分辨率和一次截图的当前方向后计算居中区域，不修改手机分辨率、不拉伸画面；被裁掉的边缘及其中的按钮不会显示。请先让手机进入想看的横屏／竖屏方向，再启动投屏；期间改变方向、手机分辨率，或将投屏移到不同比例的显示器，应停止后重新启动。修改选项也需重开投屏，F11／左 Alt+F 可随时切换全屏。裁剪不是视频内容或黑边的自动识别，视频本身嵌入的黑边不保证都能消除；若要操作完整手机界面，请切回完整显示。

方形手机屏幕无法仅凭尺寸确定旋转方向，因此向非方形显示器裁剪时会提示选择完整显示。全屏启动同时指定位于目标显示器内的初始位置和尺寸，避免较小副屏窗口中心落到主屏。

## ADB 控制台

主界面切换到“ADB 控制台”页签即可使用。左侧命令库内置 **120 条预设、10 个可折叠分类**，覆盖设备、应用、Activity/进程、权限、文件、屏幕/输入、日志、性能、网络及 ADB 服务。支持用途/命令/关键词搜索、收藏和最近使用；点击填入，不会自动执行。包名可从当前手机选择，路径支持文件/目录浏览，端口和坐标等参数在执行前校验。完整列表与操作说明见 [ADB 命令库](docs/adb-console.md)。

1. 设备命令先选择一台在线手机；`devices`、`connect`、`help` 等全局命令不使用手机选择。自定义命令可带或省略 `adb` 前缀；粘贴的 `-s` 必须与当前选择一致，执行前会显示实际目标与命令。
2. 点击“执行”或按 Ctrl+Enter。运行时固定命令与目标，结果实时显示，结束时显示退出码和耗时；切换页签不会停止当前命令。
3. 默认 2 分钟超时，可切换为 30 秒、10 分钟或持续运行。选择“实时日志”预设会自动使用持续运行，点击“停止”结束读取。停止只终止本次 ADB 客户端进程，不能撤销手机已经完成的操作。
4. 输出支持复制、保存为 UTF-8 文本、清空显示及关闭自动滚动。为保持流畅，队列和显示内容均有容量限制，超出时显示省略提示；复制和保存包含当前显示内容，并非无限期完整日志。
5. 收藏和最近 12 个预设只保存命令编号至 `%LOCALAPPDATA%/AdbDesk/console-library.json`，不保存输入参数；重新选择后按需填写。命令历史保留最近 30 条可记录的命令，支持再次填入、单条删除和清空；保存在 `%LOCALAPPDATA%/AdbDesk/command-history.json`。历史不保存目标设备，使用时以当前设备选择为准。

第一版是单条文本命令控制台，不是完整交互终端：`shell` 后需填写 Android 命令，支持 Android shell 的引号和管道；不执行 Windows cmd/PowerShell 管道、重定向或多行批处理。二进制 `exec-out` 输出请使用现有截图功能。`pair IP:端口 六位配对码` 会通过标准输入提交配对码，隐藏预览与输出中的配对码且不保存历史；不确定是否含敏感信息的自定义 shell 命令也不自动记录，预览会提示。

控制台中的安装、文件传输和网络切换结果显示在本控制台，独立于设备管理页的安装队列。预设中的卸载、清空数据、删除文件、修改设置和切换连接等操作会在执行前显示目标与命令确认；常见自定义卸载、清数据、重启等命令也会确认，但并不分析所有复杂 shell 脚本。只有明确输入并执行 `kill-server`，或在工具箱确认重启服务，才会停止共享 ADB 服务。

## 工具箱：运行中的应用

切换到“工具箱”，选择设备后可分别查看当前前台 Activity、最近任务和后台进程。列表以包名显示，包含用户 ID、Activity、PID 或任务 ID；支持搜索、复制包名和 Activity。最近任务可能保留已经退出的应用，缓存进程不代表应用持续工作。一个应用可能有多个任务或多个进程。不同 Android 版本和厂商桌面的最近任务显示可能不同，无法识别或没有权限时会显示查询异常，不会将失败伪装为空列表。

- 进入页面、切换设备或点击“刷新应用”时读取；不持续轮询应用列表。底部显示快照时间，设备离线时保留旧快照并禁用操作。
- “应用详情”查询版本等包信息与 APK 路径，详情中的文本可选中复制。
- “导出 APK”选择电脑目录，创建独立子目录并导出基础包及全部拆分 APK，不覆盖旧导出，也不包含应用数据。拆分包需要一起安装；导出中断时保留已生成的文件并提示目录。
- “查看日志”打开独立采集窗口，预填应用包名和 Android 用户，由用户点击开始。使用实际 UID 筛选，支持同 UID 多进程及进程重启；不支持 UID 的旧设备会提示改用全设备范围。
- “强制停止”确认后按指定设备、包名和用户执行，不会操作其他用户的同名应用。
- “重启 ADB 服务”确认后依次执行 `adb kill-server`、`adb start-server` 并查询服务状态。它影响电脑上所有 ADB 连接，投屏需重新启动，无线设备可能需重新连接。重启期间暂停本程序的设备轮询；安装、配对、截图或控制台任务未结束时不允许重启。不存在 `adb kill-service` 命令。

## 日志与网络抓取

工具箱新增“日志抓取”和“网络抓包”入口。日志可选全设备或应用，支持等级 / Tag / 关键词预览筛选、崩溃缓冲区、持续 UTF-8 保存和每 20 MiB 分卷。预览容量有限，完整日志保存在所选目录；关闭时等待日志写完。

网络抓包使用自带 mitmdump 便携引擎，仅监听电脑回环地址，通过所选设备的 ADB reverse 接入。点击开始后可自动设置手机全局 HTTP 代理，停止/退出恢复，离线时保留恢复记录。请求列表、请求头/正文、响应/耗时、搜索、复制与 JSON 导出都在独立窗口。保留最近 100 条和有限正文预览，不是无限历史或全 IP 抓包。

HTTPS 需要你在调试手机手动安装导出的公开 CA，并配置自己的 Debug App 信任它；不会自动修改系统信任或处理证书固定。全局代理可能包含手机其他应用的请求。完整步骤和恢复方法见 [网络调试说明](docs/network-capture.md)。源码环境运行 `scripts/setup-network-capture.ps1` 准备引擎，便携包已附带，无需安装 Python。

## 查看当前页面布局

在“工具箱”选择在线手机，点击“查看当前布局”。布局查看窗口固定目标设备，首次打开或手动刷新时依次读取 UI Automator 控件层级和手机截图，不持续轮询。

- 左侧截图、中间控件树、右侧属性联动：点击截图中的控件会展开并定位树节点；选择树节点会在截图标出边框。点击仅用于检查布局，不向手机发送点击操作。
- 属性包含设备返回的文字、resource-id、类名、包名、content-desc、bounds、clickable、enabled 等字段。支持搜索属性（回车或“下一个”循环定位）、复制属性值和复制全部属性。
- 支持导出原始 XML 和保存原始 PNG（不含选中边框）。布局与截图顺序采集，并非同一时刻，请保持手机页面静止；检测到坐标超出截图时禁用定位边框并提示重新刷新。
- 只显示系统可访问的当前窗口节点，不能还原应用源码布局。自绘页面、游戏、部分网页或 Compose 页面可能只暴露部分控件；空树、读取失败和截图失败分别提示。只读取成功一部分时仍可查看或导出该部分。
- 停止、离线或刷新失败时保留上次完整快照，并显示状态；设备重连后手动刷新。临时 XML 使用独立路径并尝试清理，不读取旧的通用 window_dump.xml。
- XML 禁用 DTD 和外部资源，限制大小、深度和节点数；取消截图仅终止本次 ADB 客户端。布局采集及清理期间，工具箱会阻止 ADB 服务重启。

## 连接与安装提示

- **待授权**：查看手机上的 USB 调试授权弹窗。
- **离线/未发现**：检查数据线、手机 USB 模式、Windows 驱动及调试开关。
- 部分品牌需要额外开启“USB 调试（安全设置）”或“USB 安装”，在手机完成确认。
- 第一版支持普通 `.apk`，不支持 `.aab`、`.apks` 或 `.xapk`。
- 默认覆盖安装并保留数据；签名冲突和版本降级会报错，不会自动卸载旧应用。
- 取消会停止排队或本地安装进程，不能撤销手机端已完成的安装。
- 不同设备的任务最多两个并发，同一台设备按顺序安装。
- 投屏窗口直接拖放由 scrcpy 管理，独立于主界面队列，不能从任务列表取消。
- 程序不会自动执行 `adb kill-server`；只有用户明确运行该命令或确认工具箱的服务重启时才会停止共享服务。
- 不需要管理员运行；普通权限也有利于从资源管理器拖放文件。

## 开发与构建

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -SkipSetup
```

SDK 安装在项目 `.tools/dotnet`，不会修改系统 SDK。官方工具在 `tools/scrcpy`，下载包进行校验。
运行 `scripts/build.ps1` 会构建、执行回归测试并生成自带 .NET 运行时的便携 ZIP，输出在 `dist`。
也可直接用 `.tools/dotnet/dotnet.exe run --project src/AdbDesk.App` 开发运行。

源码：`src/AdbDesk.Core` 是进程/ADB/投屏/安装队列；`src/AdbDesk.App` 是 WPF 界面。
工具目录可用 `ADBDESK_TOOLS` 环境变量指定，其中必须包含 `adb.exe`、`scrcpy.exe` 及配套文件。
验证范围见 `docs/verification.md`。
