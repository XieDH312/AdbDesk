# AdbDesk 安卓设备助手

Windows 10/11 x64 桌面工具。设备列表自动刷新，每台手机独立投屏窗口，鼠标键盘控制，APK 拖放安装。

主程序在同一 Windows 用户会话内只运行一份。再次双击会唤醒已有主窗口；不同手机的投屏窗口仍然可以同时打开。升级后首次使用请先退出旧版本。

## 使用

1. 解压完整便携包，双击 `AdbDesk.exe`。保留旁边的运行库和 `tools` 文件夹。
2. 手机开启开发者选项、USB 调试，通过数据线连接，并在手机上允许电脑调试。主界面也会列出 ADB 已连接的网络设备。
3. 点击设备的投屏按钮，或勾选多台后批量投屏。窗口彼此独立，关闭一台不影响其他手机。
4. APK 拖入某台设备行或其投屏窗口，安装到该设备。拖到公共安装区域或点击安装按钮，会展示选中目标，确认后安装。
5. 安装任务列表显示主界面发起的安装结果；投屏窗口直接拖放产生的结果显示在投屏日志中。

设备行显示设备名称、型号、Android 版本、连接方式和序列号。未授权或读取失败时保留设备条目；部分手机不提供自定义名称，会回退显示型号。

无线设备行的“断开连接”只断开当前这条无线 ADB 连接，同时结束本工具针对该连接的投屏，其他设备不受影响。同设备有主界面安装任务时，先等待完成或取消任务。断开不会关闭手机无线调试，也不会删除配对记录；共享此 ADB 连接的其他程序也会失去对该连接的访问。其他工具或系统自动发现可能再次连接该设备。

左下角“安装任务”仍负责主界面选择 APK、设备行拖放及公共区域拖放产生的安装队列，支持查看结果、取消和双击复制详情。直接拖入投屏窗口的 APK 由 scrcpy 安装，只在右侧投屏日志中显示输出。

## 扫码连接 / 配对码连接（Android 11+）

支持手机系统自带的“无线调试”，无需先插 USB。手机连接 Wi-Fi，电脑和手机位于可互通的同一局域网。部分定制系统没有此入口时，可继续使用下方的 USB 切换方式。

**扫码连接：**

1. AdbDesk 主界面点击“无线连接”，在弹出窗口选择“扫码连接”。
2. 手机进入“开发者选项 → 无线调试”，开启开关，再点“使用二维码配对设备”。
3. 使用该入口扫描电脑上的二维码。程序自动配对并尝试连接，确认连接成功后即可在设备列表投屏或安装 APK。
4. 二维码两分钟后过期，可点击刷新生成新码。关闭配对窗口或切换方式会停止等待和后续请求；已经提交给 ADB 的配对仍可能完成。请使用无线调试里的扫码入口，而非普通相机或微信扫一扫。

**配对码连接：**

1. 手机进入“无线调试 → 使用配对码配对设备”，保持配对弹窗打开。
2. AdbDesk 点击“无线连接”，在弹出窗口选择“配对码连接”，填写手机弹窗里的“IP 地址和端口”及六位配对码，再开始配对。
3. 程序配对后自动尝试连接。若只提示已配对，请回到手机的无线调试主页，填写该页“IP 地址和端口”到手动连接区域，然后连接。

手机的**配对端口**和**连接端口**是两个不同端口，不能混用，也不要固定填写 5555。配对码窗口可选的连接地址使用同一手机无线调试主页显示的地址，两处手机 IP 应一致。目前手动地址输入支持 IPv4。

扫码需要局域网自动发现（mDNS）。访客网络、AP 隔离或公司网络策略可能导致发现失败；此时可以改用配对码，手动填写两个地址。配对凭据只用于本次操作，不写入 AdbDesk 日志或配置；ADB 自身按系统机制保存已配对设备的信任关系。关闭本工具不会撤销已完成的配对；需要停用时，在手机无线调试中关闭开关或删除已配对电脑。

说明依据：[Android 无线调试文档](https://developer.android.com/studio/run/device#wireless)、[AOSP 配对协议](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/docs/dev/adb_wifi.md)。

## USB 切换无线连接

1. 手机和电脑接入同一可互通的局域网，手机连接 Wi-Fi，先插 USB 数据线并允许调试。
2. 在 USB 设备行点击“开启无线”。程序读取手机 Wi-Fi 地址，开启 ADB TCP/IP 5555 并尝试连接；提示连接成功后再拔数据线，从网络设备行投屏。
3. 要停止 TCP/IP 调试，重新插 USB 数据线，在 USB 设备行点击“关闭无线”，手机 ADB 会切回 USB 模式。

开关只对已授权的 USB 设备可用。切换会重启手机的 ADB 服务，可能中断投屏；安装期间请先等待任务结束。若提示无线模式已开启但连接失败，保留 USB，检查同网段、防火墙和路由器客户端隔离。

这里的“无线”指通过 USB 开启的 ADB TCP/IP，不是手机 Wi-Fi 开关，也不是 Android 11+ 的无线调试配对开关。请在可信局域网使用，用完关闭。操作依据见 [Android 官方 ADB 文档](https://developer.android.com/tools/adb#wireless)。

鼠标左键点击/拖动对应触摸，右键返回，中键回到桌面；快捷键行为以 scrcpy 官方文档为准。
质量选项对新打开的投屏生效。多台投屏建议使用较低画质并关闭声音。

## 连接与安装提示

- **待授权**：查看手机上的 USB 调试授权弹窗。
- **离线/未发现**：检查数据线、手机 USB 模式、Windows 驱动及调试开关。
- 部分品牌需要额外开启“USB 调试（安全设置）”或“USB 安装”，在手机完成确认。
- 第一版支持普通 `.apk`，不支持 `.aab`、`.apks` 或 `.xapk`。
- 默认覆盖安装并保留数据；签名冲突和版本降级会报错，不会自动卸载旧应用。
- 取消会停止排队或本地安装进程，不能撤销手机端已完成的安装。
- 不同设备的任务最多两个并发，同一台设备按顺序安装。
- 投屏窗口直接拖放由 scrcpy 管理，独立于主界面队列，不能从任务列表取消。
- 程序不会执行 `adb kill-server`，只关闭自己创建的投屏和安装进程。
- 不需要管理员运行；普通权限也有利于从资源管理器拖放文件。

## 开发与构建

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -SkipSetup
```

SDK 安装在项目 `.tools/dotnet`，不会修改系统 SDK。官方工具在 `tools/scrcpy`，下载包进行校验。
运行 `scripts/build.ps1` 会构建、执行回归测试并生成自带 .NET 运行时的便携 ZIP，输出在 `dist`。
也可直接用 `.tools/dotnet/dotnet.exe run --project src/AdbDesk.App` 开发运行。

源码：`src/AdbDesk.Core` 是进程/ADB/投屏/安装队列；`src/AdbDesk.App` 是 WPF 界面。
工具目录可用 `ADBDESK_TOOLS` 环境变量指定，其中必须包含 `adb.exe`、`scrcpy.exe` 及配套文件。
验证范围见 `docs/verification.md`。
