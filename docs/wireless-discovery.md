# 无线 ADB 服务发现

1. 手机打开无线调试；首页点击“发现设备”。列表读取当前 mDNS 广播和 ADB 设备状态。
2. 选择 TLS 或传统 TCP 服务的“连接”，程序确认在线后写入连接历史。配对服务使用“配对”进入配对码页，输入手机当前六位码；配对后自动寻找连接服务。
3. 手机重开无线调试、端口改变后点击刷新；连接按钮也会重新检查服务地址。无法唯一识别新端点时，请在刷新后的列表重新选择。
4. 名称可显示设备当前名称、型号或“历史名称”；历史名称仅作识别提示，不证明设备在线或仍已配对。USB 与无线状态独立。
5. 取消或关闭窗口停止本次发现；无永久后台扫描。不修改手机 VPN 或 ADB 的自动重连配置。

## 手工验收（需在允许运行 AdbDesk 的电脑上进行）

- 同时连接两台 USB、一条 IP 无线及一条 mDNS 无线：只为精确匹配的无线服务显示已连接。
- 重开小米无线调试，确认发现列表端口改变且点击连接使用新端口；同 IP 的旧端口不能标记已连接。
- 打开手机配对码弹窗：列表有独立配对行，预填配对地址并清除旧的连接端口/Wi-Fi 地址覆盖选项。
- 手机未配对或断网：显示实际失败结果，不保存成功历史；可手动配对/连接。配对成功但连接尚未成功时，也刷新发现列表；窗口繁忙时合并为操作结束后刷新一次。
- 无线设备正在安装时尝试断开：提示等待；正常断开时仅停止该连接的投屏。
- 发现过程中取消、关闭后重开、关闭主窗口：无晚到结果覆盖新窗口；重启 ADB 前需关闭发现窗口。
- 缩窄主窗口到最小宽度以及高 DPI：顶部按钮换行，输入组完整；服务窗口可滚动。

本次自动验证为 Release 构建和回归测试编译。当前电脑曾受 Windows 智能应用控制限制，不绕过策略执行生成的测试、GUI 或 ADB。
