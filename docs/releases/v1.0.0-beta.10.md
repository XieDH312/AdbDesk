# AdbDesk 1.0.0-beta.10

versionCode：10010。Windows 10/11 x64 便携测试版。

## 记住投屏设置

- 主界面的“投屏质量”“传输音频”“默认显示”“启动时全屏”会在选择改变时自动保存，下次打开恢复上次状态，包括取消勾选的状态。
- 偏好保存在当前 Windows 用户的 `%LOCALAPPDATA%/AdbDesk/mirror-preferences.json`，移动程序目录或更新程序后继续保留。
- 恢复选择不会自动开始投屏；修改对重新打开的投屏生效。单台设备保存的显示模式和全屏设置继续优先于主界面的默认项。
- 缺失或损坏的配置回退到初始默认值；已经移除或无法识别的选项保留对应默认项。保存失败时提示原因，不中断当前操作。

## 更新诊断

- 异常堆栈不再显示编译电脑的完整源码目录，只保留类名、方法名、源码文件名和行号，例如 `UpdateService.cs:line 198`。
- 更新窗口、复制及新保存的诊断统一采用此格式；复制旧版诊断时也会缩短其中的源码路径。
- 异常原因、实际文件错误涉及的路径和请求地址继续保留，方便排查。此项调整诊断格式，GitHub 网络和限流问题仍需按实际网络情况处理。

## 安装和更新

源码同步至 GitHub 和 Gitee。直接使用请下载附件 `AdbDesk-v1.0.0-beta.10-win-x64.zip`，完整解压到可写目录；Source code 压缩包需要自行构建。

beta.2 及以上可在右下角“检查更新”，开启“接收测试版本”后下载并更新。手动更新请先退出旧版和投屏，再将完整便携包解压到新目录运行。个人设置位于 LocalAppData。

沿用原有更新公钥及 RSA-PSS 签名清单，按 versionCode 判断升级。更新签名用于应用自身完整性校验，不是 Windows 代码签名。

## 验证范围

完整 Release 解决方案构建通过；命令库 Python 审计和网络采集 Python 用例通过。受既有应用控制运行限制，C# 用例只编译，未运行 GUI、ADB、真机或应用内替换流程。

更新后请更换质量及默认显示，分别勾选／取消音频和全屏，退出重开检查选择恢复；已有独立显示设置的设备仍应使用自己的显示模式和全屏选项。诊断复制、保存和旧文件读取的源码路径显示也请手动检查。
