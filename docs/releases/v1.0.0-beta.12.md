# AdbDesk 1.0.0-beta.12

versionCode：10012。Windows 10/11 x64 便携测试版。

## 发现无线设备

- 首页顶部新增“发现设备”，列出当前局域网 mDNS 广播的无线 ADB 服务、最新地址、服务类型及连接状态。手机重开无线调试后可刷新获取新端口。
- 支持系统无线调试（TLS）、传统 TCP 调试和配对服务；可以连接、断开、复制地址，或进入配对码窗口。配对端口不会当作连接端口使用。
- 已连接设备读取当前名称或型号；此前验证过的名称可作为“历史名称”显示。无法识别的服务保留服务名，不凭 IP 猜测设备名称；USB 在线不等于对应无线服务已连接。
- 点击操作前重新核对服务和端口，无法唯一确认目标时提示刷新。断开只针对选中的无线连接；安装进行中会提示等待。
- 打开窗口、手动刷新及完成操作后读取一次，无持续后台扫描。无发现结果或 mDNS 不可用时，可继续手动配对或填写 IP 连接。

## 取消与关闭

发现窗口支持取消和关闭，限制发现等待时间；取消 ADB 客户端时保留共享 ADB 服务，并对进程输出管道实施有界清理。配对成功但连接失败时也会刷新服务状态，不记录为成功连接。

## 安装和更新

直接使用请下载 `AdbDesk-v1.0.0-beta.12-win-x64.zip`，完整解压到可写目录；GitHub 的 Source code 附件需要自行构建。

beta.2 及以上可在右下角“检查更新”，开启“接收测试版本”后下载并更新。手动更新请先退出旧版和投屏，再将完整便携包解压到新目录运行。个人设置继续保存在 LocalAppData。

沿用现有更新公钥、RSA-PSS 签名和 schema1 清单，数字版本提升到 10012。更新签名用于应用自身完整性校验，不是 Windows 代码签名。

## 验证范围

完整 Release 解决方案编译通过，0 警告、0 错误。无线服务解析、连接匹配、历史名称隔离、缓存边界、失败与取消及共享子进程保留回归用例已编译。受本机既有 Windows 策略限制，未执行 C# 测试程序、GUI、ADB、手机操作或应用内替换流程；未更改系统安全策略。

更新后请手动验证：小米重开无线调试后刷新端口；USB 与无线同时存在时状态区分；未配对手机的配对、连接及失败提示；取消和关闭发现窗口。发现依赖局域网允许 mDNS 广播，不能保证穿透 VPN 或路由器隔离。详细步骤见随包 `docs/wireless-discovery.md`。
