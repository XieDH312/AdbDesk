# AdbDesk 1.0.0-beta.9

versionCode：10009。Windows 10/11 x64 便携测试版。

## 投屏显示设置

- 设备行和投屏工具栏新增“显示设置”，支持完整显示、上下铺满、左右铺满、裁剪铺满、自定义裁剪，始终保持画面比例。
- 可在手机完整截图上拖动四角、移动选区，或按住 Shift 拖出新区域；支持四边百分比、居中、还原和电脑画面预览。
- 可按设备保存显示方式、选区和全屏设置。对正在投屏的设备应用设置时，先校验裁剪尺寸，再短暂重开这台投屏。
- 手机方向或分辨率变化后，请刷新截图并重新选择区域；同宽高的 180° 旋转需要手动调整。视频自身的黑边可通过选区排除，裁剪会隐藏边缘内容。

## 投屏工具栏与操作帮助

- 工具栏提供“显示设置”“手机熄屏”“手机亮屏”“操作帮助”；熄屏请求使用 scrcpy 的实体屏幕控制，电脑端继续投屏。
- 普通窗口优先停靠在窗口右侧外部；空间不足时尝试左侧、上方、下方，避开任务栏。
- 全屏或外侧空间不足时默认隐藏，鼠标移到投屏窗口顶部边缘展开，离开约 0.8 秒后收起。打开帮助或显示设置期间保留工具栏，避免对话框随工具栏隐藏。
- 操作帮助支持分类、搜索和复制，主界面右上角“使用帮助”也可打开。悬停按钮可查看快捷键：左 Alt + O 熄屏，左 Alt + Shift + O 亮屏，F11 切换全屏。

## 安装和更新

源码同步至 GitHub 和 Gitee。直接使用请下载附件 `AdbDesk-v1.0.0-beta.9-win-x64.zip`，完整解压到可写目录；Source code 压缩包需要自行构建。

beta.2 及以上可在右下角“检查更新”，开启“接收测试版本”后下载并更新。手动更新请先退出旧版和投屏，再将完整便携包解压到新目录运行。个人设置位于 LocalAppData。

保留数字 versionCode 比较、原有更新公钥及 RSA-PSS 签名清单。这是应用更新完整性校验，不是 Windows 代码签名，系统智能应用控制策略仍适用。

## 验证范围

完整 Release 解决方案和新增 C# 回归用例已编译；命令库 Python 审计、网络采集 Python 用例通过。显示设置、按键提交、外侧停靠与自动隐藏已完成静态复核。

受既有应用控制运行限制，C# 行为测试、GUI、ADB、真机控制和应用内替换流程未执行。多显示器缩放、工具栏位置和手机熄屏／亮屏效果请在可运行程序的电脑上测试，步骤见 `docs/mirror-display.md`。
