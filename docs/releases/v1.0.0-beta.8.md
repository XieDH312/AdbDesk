# AdbDesk 1.0.0-beta.8

versionCode：10008。Windows 10/11 x64 便携测试版。

## 投屏显示

- 新增“裁剪铺满 · 保持比例”和“启动时全屏”。先将手机转到观看方向，选择显示方式后停止并重开投屏。
- 根据手机当前分辨率、截图方向及 AdbDesk 所在显示器比例计算居中裁剪，保持画面比例，不修改手机分辨率。F11／左 Alt+F 切换全屏。
- 保留完整显示和独立多设备窗口。准备裁剪时可取消启动，停止所选和退出也会取消准备中的任务。
- 裁剪会隐藏边缘内容。改变手机方向、分辨率或目标显示器比例后需要重开投屏；视频内嵌黑边不保证消除。方形手机屏向非方形显示器裁剪时明确提示使用完整显示。

## 更新检查

- 检查更新的总时限从 15 秒调整为 60 秒，覆盖发行列表和候选版本的全部元数据读取。
- 失败诊断显示具体读取步骤；重试成功后旧异常标为历史并折叠，诊断文件保留。
- 保留数字 versionCode 比较、原有更新签名和文件完整性校验。

## 源码和安装

源码、测试及构建脚本同步至 GitHub 和 Gitee。直接使用请下载附件 `AdbDesk-v1.0.0-beta.8-win-x64.zip`，完整解压到可写目录；Source code 压缩包需要自行构建。

beta.2 及以上可在右下角“检查更新”，开启“接收测试版本”后下载并更新。旧版检查超时时可先手动下载完整便携包，退出旧版与投屏后解压到新目录运行。个人设置位于 LocalAppData。

## 验证范围

相关 C# 测试已编译，完整 Release 解决方案构建通过；C# 行为测试、GUI、ADB、真机控制和应用内替换流程尚未执行。裁剪与取消流程已完成静态复核，真实设备效果请手测。

更新包使用 RSA-PSS 签名清单验证完整性，这不是 Windows 代码签名。系统智能应用控制策略仍适用。
