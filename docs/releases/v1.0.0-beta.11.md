# AdbDesk 1.0.0-beta.11

versionCode：10011。Windows 10/11 x64 便携测试版。

## 应用名称与搜索

- “工具箱 → 应用管理”新增名称列，支持按名称或包名模糊搜索；详情标题及“复制信息”同时包含名称和准确包名。
- 先显示完整包名列表，再补充名称。读取期间可以搜索、筛选和选择应用；取消或读取失败时保留列表，显示具体原因，完成后读取所选应用详情。
- 复用随程序附带的 scrcpy 读取名称，无需安装辅助 App，也不为读取名称下载手机 APK。暂不读取图标。
- 名称目前只覆盖 Android 用户 0 中已启用且有启动入口的应用；系统组件、已停用应用或其他用户的应用仍保留包名，名称显示“未读取”。每次刷新重新读取名称，设备之间不共用缓存。

## 应用详情与调试联动

- 基本信息显示 versionName、versionCode、最低／目标 SDK、安装／更新时间和 APK 路径，系统未报告的字段明确标为未知。
- 权限页分别展示申请权限、安装时授权和当前 Android 用户的运行时授权；解析区分活动包与重复系统包，避免混入其他用户状态。
- 新增打开手机应用设置、复制完整信息及“抓取此应用日志”。日志窗口带入设备、包名和用户，点击开始后才采集；已有采集不会被覆盖。
- 继续支持启动、强制停止、导出 base 与全部 split APK、清除数据和当前用户卸载，关键操作明确对应设备与用户。

## 安装和更新

直接使用请下载 `AdbDesk-v1.0.0-beta.11-win-x64.zip`，完整解压到可写目录；GitHub 的 Source code 附件需要自行构建。

beta.2 及以上可在右下角“检查更新”，开启“接收测试版本”后下载并更新。手动更新请先退出旧版和投屏，再将完整便携包解压到新目录运行。个人设置继续保存在 LocalAppData。

沿用现有更新公钥、RSA-PSS 签名和 schema1 清单，数字版本提升到 10011。更新签名用于应用自身完整性校验，不是 Windows 代码签名。

## 验证范围

完整 Release 解决方案编译通过，0 警告、0 错误。新增名称解析、用户隔离、错误与取消、有界 UTF-8 读取及详情／权限解析用例已编译，未执行 C# 测试程序、GUI、ADB、手机操作或应用内替换流程；未更改系统安全策略。

更新后请手动核对名称搜索、长中文名称、停止读取后的列表、详情与权限、打开设置及日志带入范围，并确认右下角版本显示 beta.11／10011。名称读取不到时，可继续按包名管理并查看列表下方原因。
