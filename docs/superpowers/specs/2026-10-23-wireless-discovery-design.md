# 无线 ADB 服务发现

用户已在对话中确认按需发现方案，并要求执行。

在顶部增加“发现设备”，打开独立、单实例服务窗口。打开、手动刷新以及连接/配对/断开后刷新；无后台周期发现。支持 TLS 连接、传统 TCP 和配对三种服务，展示名称、最新 IP:端口、类型、实际连接状态和对应操作。

连接前重新发现并按完整服务身份选最新端口。已连接只认无线传输的精确 endpoint 或完整 mDNS serial；USB、同 IP、同型号均不作为无线在线证据。配对服务只进入配对页，不执行 connect。

名称来自已验证在线设备；缓存按完整服务名和类型隔离，并标明历史名称。服务身份变化时不猜测。未知设备保留服务标识。缓存失败不阻断发现。

方案选择：复用 adb mdns services 和现有 PairingService/AdbService；本次按需发现比持续轮询更符合用户此前的刷新偏好。全网端口扫描不属于当前范围。发现服务不保证可访问或已配对。

约束：保留现有手动输入和配对功能；不更改 VPN、ADB 全局自动连接策略；关闭/重启/重建服务时取消窗口操作；不新增第三方依赖；不发布版本。
