# AdbDesk Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement tasks and review their integration.

**Goal:** Deliver a runnable Windows ADB manager with separate controllable mirror windows and targeted APK drag/drop installs.

**Architecture:** WPF UI consumes Core services. Core invokes fixed official ADB/scrcpy binaries with argument arrays and owns only its child processes. Publishing copies tools and the .NET runtime.

**Tech Stack:** C#, .NET 10, WPF, scrcpy 4.1, bundled ADB.

**Spec:** docs/superpowers/specs/2026-09-11-adbdesk-design.md

## Global Constraints
- Windows 10/11 x64; Chinese UI; separate mirror windows.
- Each device operation explicitly routes by serial. No global adb kill-server, uninstall, or downgrade.
- Same-device installs serialize; at most two global concurrent installs; cancellation and bounded command timeouts.
- Official pinned tools, local SDK, preserve dependency licenses; no unrelated directory edits.
- UI and Core signatures are defined in the spec and are binding.
