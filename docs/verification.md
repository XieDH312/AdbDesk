## 用户手动验收

用户按 Esc 停止 Computer Use 后明确选择自行测试；此后不再进行桌面自动操作。

1. 使用最终 `dist` 便携包的 `AdbDesk.exe`，关闭旧 Debug 窗口，避免把旧版本当作最终版本。
2. USB 连接并确认调试授权，检查就绪/未授权/离线提示及插拔刷新。
3. 启动单台投屏，测试点击、拖动、长按、返回和关闭窗口后状态恢复。
4. 投屏窗口直接拖入普通 APK，查看手机安装结果及“投屏日志”。
5. 拖 APK 到设备行；再用公共安装入口选择目标；检查安装任务结果与实际目标一致。
6. 两台真机同时投屏，分别操作；仅关闭一台不影响另一台。
7. 测试同设备多 APK 排队、取消任务、签名冲突、设备中断等情况。
