## 用户手动验收

用户按 Esc 停止 Computer Use 后明确选择自行测试；此后不再进行桌面自动操作。

1. 使用最终 `dist` 便携包的 `AdbDesk.exe`，关闭旧 Debug 窗口，避免把旧版本当作最终版本。
2. USB 连接并确认调试授权，检查就绪/未授权/离线提示及插拔刷新。
3. 启动单台投屏，测试点击、拖动、长按、返回和关闭窗口后状态恢复。
4. 投屏窗口直接拖入普通 APK，查看手机安装结果及“投屏日志”。
5. 拖 APK 到设备行；再用公共安装入口选择目标；检查安装任务结果与实际目标一致。
6. 两台真机同时投屏，分别操作；仅关闭一台不影响另一台。
7. 测试同设备多 APK 排队、取消任务、签名冲突、设备中断等情况。
8. 退出旧版后启动新版，再次双击同一个 EXE；主程序应只保留一份。最小化主窗口后再次启动，应恢复已有窗口。退出后应能重新启动。
9. 检查名称、型号、Android 版本和 USB/网络连接标记；未授权设备仍显示基本条目。设备名称更改后等待约 30 秒刷新。
10. 手机连 Wi-Fi，电脑位于同一局域网，保留 USB 数据线。点击“开启无线”，收到连接成功结果后拔线，从新增的网络设备行投屏。
11. 重新插 USB，点击 USB 设备行“关闭无线”。确认结果后检查网络连接停止、USB 连接仍可使用。
12. 手机 Wi-Fi 未连接时点击开启，应提示缺少地址；路由器隔离等导致连接失败时，应提示 TCP/IP 已开启但未连接，保持 USB 后可关闭或重试。
13. 主界面安装任务排队/执行时不应允许切换无线；切换期间从主界面提交安装应被拦截。

## 扫码与配对码功能手动验收

1. 使用本轮新包，先退出旧版。手机 Android 11+，连接 Wi-Fi，开启开发者选项中的无线调试；电脑与手机处于同一局域网。
2. 点击“扫码连接”，用手机“无线调试 → 使用二维码配对设备”的扫码入口扫描。检查电脑提示连接成功、设备自动显示，并能打开投屏和操作。
3. 刷新二维码，旧二维码不应再触发新请求；切换到配对码页或关闭窗口后，不应继续发现或提交旧会话的请求。二维码过期后应有提示。已经提交到 ADB server 的配对可能仍会完成，不把这一情况误判为客户端继续提交请求。
4. 点击“配对码连接”，填写手机“使用配对码配对设备”弹窗中的地址与六位代码。检查正确输入成功，错误代码明确失败。
5. 模拟不能自动发现连接的网络，确认已配对但未连接时有明确提示；填写手机无线调试主页的连接地址后，点击手动连接并检查设备就绪。
6. 分别检查无效地址、无效端口、配对码不足六位、手机关闭无线调试、等待期间取消/关闭、重复点击入口等情况。连接地址与配对地址的端口不得混淆。
7. 同网存在多台手机时，扫码只配对当前二维码对应的手机，配对码只使用填写的目标；不能因另一台手机在线就显示本次连接成功。

关闭窗口或程序不能撤销 ADB server 已经接收或手机端已经完成的配对。要停用已授权电脑，在手机无线调试设置中删除该电脑；关闭无线调试可停止该模式下的连接。
