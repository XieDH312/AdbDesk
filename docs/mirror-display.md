# 投屏显示设置

本功能从 v1.0.0-beta.9（versionCode 10009）提供，发行附件以 GitHub Releases 为准。

设备行点击“显示设置”，或使用投屏工具栏。窗口模式下，工具栏优先停靠在投屏窗口右侧外部；空间不足时依次选择左侧、上方或下方，不固定遮住手机画面。位置受当前显示器工作区限制，避开任务栏。

全屏或四周都没有足够空间时，工具栏默认隐藏：鼠标移到投屏窗口顶部边缘展开，再移到按钮上操作；离开边缘和工具栏约 0.8 秒后收起，不保留常驻按钮覆盖画面。正在使用工具栏打开的帮助或显示设置时，暂时保留其所属工具栏，避免所属窗口隐藏导致帮助一起消失。

工具栏跟随对应投屏窗口，切换到其他应用或最小化投屏时隐藏，停止投屏后关闭。主界面的设备行和右上角“使用帮助”始终保留入口。

## 工具栏和操作帮助

工具栏提供“显示设置”“手机熄屏”“手机亮屏”“操作帮助”。悬停查看按钮说明和快捷键。屏幕按钮会先激活对应的投屏窗口，检查窗口和焦点，再一次提交完整快捷键；校验失败时提示重试。工具栏和主界面运行日志显示发送结果，不把提交请求当作手机状态的确认。

“手机熄屏”使用 scrcpy 的关闭实体显示功能，电脑端投屏和控制继续。“手机亮屏”恢复手机显示。使用按钮前请松开电脑的 Ctrl、Alt、Shift 和 Windows 键；无法激活投屏时会提示重新点击画面。若按钮未生效，可点击投屏画面后直接用快捷键检查设备支持情况。

“操作帮助”按屏幕电源、窗口显示、触摸导航、通知栏、音量、文本等分类列出常用操作，支持搜索和复制列表。帮助窗口可保持打开，拖到旁边对照操作。主界面右上角“使用帮助”也展示同一份投屏操作，另有“连接、安装与授权”页。

| 操作 | 快捷键 |
| --- | --- |
| 手机熄屏，保留电脑投屏 | 左 Alt + O |
| 手机亮屏 | 左 Alt + Shift + O |
| 全屏 / 退出全屏 | F11 / 左 Alt + F |
| 返回 / Home / 最近任务 | 左 Alt + B / H / S |
| 音量增加 / 减少 | 左 Alt + ↑ / ↓ |

先点击投屏画面再按快捷键。Alt 指左 Alt，O 是字母。手机实体电源键会让屏幕重新亮起。官方行为说明见 [scrcpy v4.1 device.md](https://github.com/Genymobile/scrcpy/blob/v4.1/doc/device.md#turn-screen-off) 和 [shortcuts.md](https://github.com/Genymobile/scrcpy/blob/v4.1/doc/shortcuts.md)。

## 显示方式

- 完整显示：保留整块手机屏幕，忽略自定义选区。
- 上下铺满：按高度等比填满，左右超出的内容居中裁掉；较窄的画面仍可能有左右留边。
- 左右铺满：按宽度等比填满，上下超出的内容居中裁掉；较宽的画面仍可能有上下留边。
- 裁剪铺满：填满宽高，按电脑显示器比例居中裁掉超出的部分。
- 自定义裁剪：只显示选定区域，保持比例缩放。

所有模式均保持比例，不拉伸画面。播放器画面内部的黑边需要在手机完整截图上手动排除：拖动四角缩放选区，拖动选区内部移动；按住 Shift 拖动新建选区。右侧可填写左、右、顶、底各裁掉多少百分比，提供“居中选区”“还原选区”。手机完整截图和电脑画面预览联动，预览是手动刷新快照，不会持续截屏。

选区也可配合上下、左右或裁剪铺满：先选出视频内容，再选择相应铺满方式。选择完整显示暂时忽略选区。自定义区域至少保留原图宽高的 2%。

## 应用和保存

“应用设置”对当前设备生效；若正在投屏，会先读取并校验新裁剪所需的尺寸，再短暂重开这台设备的投屏。其他设备保持原状。设置窗口会识别当前投屏所在的显示器以及当前是否全屏；也可在设置中勾选或取消全屏。F11 仍可切换投屏窗口全屏。

“记住此设备的设置”保存到 `%LOCALAPPDATA%/AdbDesk/mirror-display.json`。文件只含当前连接标识、型号、显示模式、选区比例、源尺寸和全屏选项，不保存截图。未勾选时只在本次 AdbDesk 运行期间记忆，并移除此连接原来保存的设置。USB 与不同无线连接标识独立保存，不凭设备名称合并。

主界面“默认显示”及“启动时全屏”只用于尚未单独设置的设备。已单独设置的设备通过设备行或投屏浮动按钮修改。

手机方向或分辨率改变后，请重新打开设置并刷新手机画面。检测到已保存的自定义区域源尺寸不同，会要求重新选择，不能直接拿旧坐标裁新画面。同宽高的 180° 旋转无法仅凭尺寸识别，需要手动刷新调整。移动到不同比例的显示器后也应重新应用显示设置。

## 手动测试

1. 分别连接两台设备，仅修改其中一台。确认另一台的投屏及设置不变。
2. 用宽屏横屏画面切换“上下铺满”“左右铺满”，对照预览验证裁剪与留边；确认人物比例不变。
3. 用竖屏画面重复测试，检查宽度铺满会裁掉上下，完整显示可恢复整屏。
4. 选一个明显不居中的小区域，检查预览与实际投屏区域、鼠标控制位置一致。
5. 检查 Shift 拖选、四角缩放、内部移动、四边百分比、居中、还原。非法比例应禁用应用并提示。
6. 在窗口和 F11 全屏中打开浮动按钮；切换到其他应用、最小化、停止、关闭投屏，检查无残留按钮。双显示器不同缩放比时，检查按钮和对话框的位置。
7. 应用时断开设备或关闭设置，检查不会误操作其他设备，也不会遗留截图采集。原画面在新裁剪准备失败时保持运行。
8. 勾选记忆后退出重开，检查该连接设置恢复；取消记忆后重开应使用主界面默认设置。
9. 保持两台手机投屏，分别点击一台的“手机熄屏”“手机亮屏”，检查电脑端画面和控制继续，另一台不变；窗口、全屏和窄窗口中分别测试。
10. 两个入口打开操作帮助，搜索“熄屏”“音量”，复制列表；把帮助放到旁边，先点击投屏画面，再对照快捷键操作。
11. 关闭对应投屏，检查其工具栏及帮助窗口关闭；主界面的帮助仍可独立使用。按住电脑修饰键点击屏幕按钮时应提示先松开，不应释放用户的按键。
12. 手机窗口移到屏幕左右边缘、顶部或底部，检查工具栏在有空位的外侧停靠且避开任务栏；两侧、上方、下方均无空间时应自动收起。
13. F11 进入全屏，首次不应显示工具栏覆盖画面。移到最顶部边缘再移到工具栏，检查可点击、停留不闪退；移开约 0.8 秒后收起。退出全屏应恢复外侧停靠。

裁剪坐标转换依据 [scrcpy v4.1 ScreenCapture](https://github.com/Genymobile/scrcpy/blob/v4.1/server/src/main/java/com/genymobile/scrcpy/video/ScreenCapture.java) 和 [VideoFilter.addCrop](https://github.com/Genymobile/scrcpy/blob/v4.1/server/src/main/java/com/genymobile/scrcpy/video/VideoFilter.java)：奇数旋转时对矩形四边转置。手机点击坐标映射继续由原版 scrcpy 处理。
